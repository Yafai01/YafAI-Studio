# 🚀 DeepSeek Code Generator

An open-source AI-powered Python code generator using **DeepSeek** models.

## 🧠 Backend
- FastAPI
- DeepSeek Coder
- Runs locally or on Render

## 🌐 Frontend
- Next.js
- Deployed on Vercel

## 🏃 Run Locally

### Backend
\\\ash

### Frontend
\\\ash
